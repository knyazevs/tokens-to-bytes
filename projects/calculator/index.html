Что здесь происходит

Интерфейс не знает, на каком языке написана логика: он вызывает 17 экспортов, а состояние ввода, дроби, backspace, смена знака, цепочки операций и повтор = живут внутри wasm. Переключатель сверху меняет модуль, не меняя ни одной строки UI-кода.

Реализации

  • calc.wasm — ручной байткод (calc.wat — его текстовая форма);
  • calc-rust.wasm, calc-assemblyscript.wasm, calc-c.wasm, calc-cpp.wasm — сборки из Rust / AssemblyScript / C / C++; calc-cpp-opt.wasm — тот же C++ с -O3 вместо -Oz.

Запуск

Страница открывается двойным щелчком: для ручной сборки в HTML встроена base64-копия, поэтому file:// работает без сервера. Остальные движки загружаются через fetch — для них нужен локальный сервер, например python -m http.server.

Экспорты

digit(i32), dot(), back(), neg(), op(i32), equals(), clear(), ce(), display() → f64, acc() → f64, cur() → f64, opCode() → i32, lastOp() → i32, fresh() → i32, error() → i32, operand() → f64, leftOperand() → f64.

Коды операций: 1 = +, 2 = −, 3 = ×, 4 = ÷. Подробности и измерения — в статье.
