Бенчмарк калькулятора

Шесть сборок, одинаковый API и одинаковая нагрузка. Проверка корректности и скорость выполнения — в одном запуске, прямо в браузере. Каждая сборка измеряется в своём Worker.

  • Нагрузка: 12 последовательностей, 76 вызовов API за проход. Каждая сборка измеряется в отдельном Worker: прогрев 500 мс, 7 раундов по 150 мс; в таблице — медиана и коридор min–max. Числа — вызовы API в секунду.
  • Изоляция нужна, чтобы V8 не делил бюджет оптимизации между несколькими горячими wasm-модулями: иначе последняя измеренная сборка проседает в 2–3 раза.
  • gzip считается в браузере через CompressionStream; размер — байты самого модуля.
  • Методика и Node-числа — в статье и таблице результатов.
  • Для загрузки внешних wasm нужен HTTP-сервер: python -m http.server в корне репозитория.
